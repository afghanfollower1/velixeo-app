Trigger signed Android build - VELIXEO v0.9.9 - 2026-09-23.
Release scope:
1) Promotions is removed from the customer app and Admin UI for now.
2) Promotions/Meta connection APIs are disabled; historical database/orders are preserved rather than deleted.
3) Promotion services, banners, notifications and customer-order history are hidden from customer-facing surfaces.
4) Shared Admin Orders/Banners/Notifications no longer surface Promotions records.
5) Premium is now strictly for premium subscriptions such as Telegram Premium, Snapchat+ and similar services.
6) VPN, Netflix, streaming, licenses, AI/digital products belong in the separate Digital Accounts section.
7) Added a dedicated Digital Accounts app hub driven by DIGITAL_ACCOUNT catalog items.
8) Mobile Top-up remains visible only as Coming soon until official telecom provider APIs are connected.
9) Admin Mobile Top-up is also a Coming soon page; unused provider/product controls are hidden for now.
10) Home/service loading is staged so catalog and banners render before heavier order/notification data.
11) Payment capability/history calls are deferred until the Add Funds screen is opened.
12) Home, Social, Virtual Numbers and Premium banner image decoding/loading was optimized for the actual device width.
13) Backend and Flutter validation passed before this release trigger.
