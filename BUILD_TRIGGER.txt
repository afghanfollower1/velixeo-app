Trigger signed Android build - VELIXEO v0.9.8 - 2026-09-23.
Release scope:
1) Promotions adds official Meta/Instagram account connection using Meta OAuth.
2) Customer credentials are entered only on Meta's official login page; VELIXEO never stores Instagram/Facebook passwords or OTPs.
3) Authorized access tokens are encrypted server-side with AES-256-GCM.
4) Connected Facebook Page and Instagram Professional account IDs, usernames, Page tasks, granted permissions and ad-account metadata are stored for fulfillment.
5) Customer can load and select their own Instagram posts/Reels inside VELIXEO.
6) Promotion orders snapshot the selected Instagram account and media ID.
7) Telegram paid-order invoices include the connected Instagram account, selected media and ADVERTISE readiness.
8) Promotions Admin adds an Instagram Connections workspace with customer/account/Page/permission details and no secret-token exposure.
9) Partnership Ad Code remains an optional fallback.
10) Manual Meta campaign fulfillment remains the current execution mode; automatic Marketing API campaign creation is not enabled yet.
11) Production Instagram login requires META_APP_ID, META_APP_SECRET and META_REDIRECT_URI from a Meta Business App.
12) Backend and Flutter validation passed before this release trigger.
