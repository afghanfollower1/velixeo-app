Trigger signed Android build - VELIXEO v0.9.3 - 2026-09-21.
Release scope:
1) Normalize 5SIM SMS delivery-rate values so fractional API rates display as real percentages.
2) Preserve all operator rows returned by 5SIM, including array/object response variants and deduplication by country/service/operator.
3) Manual Virtual Numbers mirrors 5SIM comparison: price-sorted operators, per-operator stock, SMS delivery %, lowest/highest price, best-delivery tags, plus Any operator.

5) Country flags/names are resolved from complete ISO metadata with aliases instead of partial hardcoded flags.
6) Known services use brand icons/colors; every unknown 5SIM service gets a visible deterministic initials badge instead of a missing generic icon.
7) My Numbers is organized into Active / Completed / Cancelled / Failed / All; completed is green, cancelled/refunded red, failed dark red; terminal orders no longer show Check SMS.
8) Virtual Numbers has an admin-managed entry banner. Admin can change image/text or disable it without an APK update; built-in information hero remains as fallback.
9) Virtual panel and app performance improvements: parallel secondary API loading, staged startup render, parallel active-order polling, fewer full-screen timer rebuilds, lightweight balance-only refresh after number actions, optimized network image decoding.
10) Backend CI and Flutter analyzer passed before this build.
