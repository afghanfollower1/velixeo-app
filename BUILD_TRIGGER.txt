Trigger signed Android build - VELIXEO v0.9.7 - 2026-09-21.
Release scope:
1) Adds the first dedicated Instagram & Facebook Promotions module.
2) Customers can choose a promotion package, provide a post/Reel URL and a Meta Partnership Ad Code without sharing passwords.
3) Promotion checkout collects objective, target countries, optional audience notes and optional website URL.
4) Wallet payment and promotion order creation are atomic; unpaid orders never enter the admin queue.
5) Telegram admin invoices include platform, post, authorization code, objective, targeting, package, duration and ad budget.
6) Admin gets a dedicated Promotions workspace with Overview, Banner, Packages, Orders and Meta Setup.
7) Promotion order lifecycle supports permission review, need information, ready to launch, active, completed and refund.
8) Admin can record Meta Campaign ID, Meta Ad ID and bilingual result summaries.
9) Refunds are idempotent and return the paid amount to the customer wallet.
10) Customers receive bilingual lifecycle notifications.
11) Promotions has a bilingual server-controlled banner plus a built-in fallback hero.
12) The app explains exactly how customers can obtain a Partnership Ad Code.
13) Mobile Top-up remains Coming Soon until official telecom APIs are available.
14) Meta Marketing API automation is intentionally deferred; v1 uses manual Ads Manager fulfillment.
15) Backend and Flutter validations passed before this release trigger.
